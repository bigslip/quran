# Phase 5 Auth & Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ensure the custom authentication stack (Email + Social) and backend synchronization logic are fully tested and compliant with the project's WAI-ARIA and DLS primitive standards.

**Architecture:** The auth components are located in `src/components/Login` and `src/pages/`. Hook and API logic are in `src/hooks/auth` and `src/utils/auth`.

## Global Constraints
- Tests must pass in Vitest (`yarn vitest run <file>`).
- Subagents must write tests *before* writing or modifying component logic (TDD).
- WAI-ARIA guidelines must be respected.
- DLS primitives (Skeleton, Spinner) should be used for loading states where appropriate, and containers must spread `HTMLAttributes` to support them.
